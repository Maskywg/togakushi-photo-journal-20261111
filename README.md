# 戶隱，走入深秋之森

2026-11-01（Day 4）的戶隱神社與鏡池旅拍特輯第一版。55 個影像檔精選 24 張，原始檔案未移動、未刪除、未覆寫。

## 預覽

直接雙擊「戶隱神社旅拍特輯_單檔預覽.html」，圖片、樣式及程式皆已內嵌，不需連線。

標準網頁為 index.html 搭配 images/。GitHub Pages：https://maskywg.github.io/togakushi-photo-journal-20261111/收藏保留在同一瀏覽器，與其他裝置或單檔版本不互通。

## 功能

五章分類、文字／編號搜尋、收藏、雙欄畫廊／單欄長卷、完整照片燈箱、5.5 秒幻燈片、左右方向鍵、Escape 關閉、手機左右滑動。

選片紀錄.csv 記錄全部 55 個檔案的入選狀態與理由。photos.json 保存 24 張照片說明與 EXIF；修改後執行 python3 work/build.py 重新產生標準版與單檔版（需 Pillow）。work/prepare.py 為 HEIC 轉 sRGB 網頁 JPEG 的製作腳本（需 pillow-heif），請保留原始來源路徑。

## 分享預覽

已製作 images/og-togakushi-v1.jpg（1200×630）並加入 Open Graph／Twitter Card。已設定正式 GitHub Pages 的 canonical、og:url 及分享圖片 HTTPS 絕對網址。
